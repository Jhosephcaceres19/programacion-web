Sobre Diavox

Una herramienta creada para simplificar la creación de presentaciones

Procesamiento local

Todo ocurre en tu navegador. Sin servidores, sin subida de datos, total privacidad.

Cero dependencias

HTML, CSS y JavaScript puro. Sin frameworks, sin build, funciona al instante.

Diseño responsive

Se adapta a cualquier pantalla: móvil, tablet, escritorio y modo presentación.

Código abierto

Proyecto académico transparente. Puedes estudiar, modificar y extender el código.
